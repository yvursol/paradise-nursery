# Paradise Nursery — Plant Shopping App

Welcome to **Paradise Nursery**, your online store for beautiful indoor plants.  
This is a React-based e-commerce application where users can browse plants, add them to a shopping cart, and manage their purchases.

## Features
- Browse plants by category
- Add/remove items to/from cart
- Update item quantities
- View total price
- Responsive design

## Technologies Used
- React
- Redux Toolkit
- React Router
- CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

Enjoy shopping at Paradise Nursery!
